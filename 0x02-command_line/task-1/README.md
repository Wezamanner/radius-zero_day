# Task 1: Linux Terminal Navigation & Environment Exploration

## Overview
This task focuses on learning basic Linux command-line operations, navigating the filesystem, exploring the Linux environment, and creating the required directory structure for the assignment.

## Commands Practised

| Command | Description |
|---|---|
| `pwd` | Displays the current working directory. |
| `ls` | Lists files and directories in the current location. |
| `ls -l` | Displays files and directories in a detailed list format. |
| `ls -la` | Lists all files, including hidden files, with detailed information. |
| `cd ..` | Moves one directory up to the parent directory. |
| `cd ~` | Navigates to the user's home directory. |
| `cd -` | Returns to the previous working directory. |
| `whoami` | Displays the currently logged-in username. |
| `hostname` | Displays the computer's hostname. |
| `date` | Displays the current system date and time. |
| `mkdir -p` | Creates directories, including parent directories when necessary. |
| `touch` | Creates empty files or updates existing file timestamps. |
| `find` | Searches for files and directories using specified conditions. |

## What I Learned

Through this task, I learned how to navigate the Linux filesystem using absolute and relative paths, identify my current working directory, inspect files and directories, and explore basic system information.

I also practised creating nested directories and README files using Linux terminal commands. Finally, I learned how to verify the created directory structure and organize my assignment files properly.
