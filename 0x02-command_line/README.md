# 0x02. Command Line Practice

## Description
This assignment is designed to introduce the fundamentals of working with the Linux command line interface (CLI). It provides practical experience in using terminal commands to navigate the filesystem, explore the Linux environment, manage files and directories, and understand basic command-line operations.

## Objectives
- Understand how to navigate the Linux filesystem.
- Identify the current working directory and logged-in user.
- Explore files and directories using different `ls` options.
- Understand absolute and relative paths.
- Practise moving between directories using `cd`.
- Create and manage directories and files using `mkdir` and `touch`.
- Verify directory structures and locate files using `find`.

## Tasks
This assignment is divided into four tasks:

- **Task 1:** Linux Terminal Navigation & Environment Exploration.
- **Task 2:** Command-line practice and filesystem operations.
- **Task 3:** Additional Linux command-line exercises.
- **Task 4:** Further practice with Linux terminal commands.

## Learning Outcome
By completing this assignment, I gained practical experience using the Linux terminal, improved my understanding of filesystem navigation, and developed confidence in performing basic file and directory management operations through command-line instructions.
